# song-views.html 開発記録

`holo_pokajan/song-views.html`（ホロドリ ソロ楽曲 再生数伸び率一覧）まわりの機能追加・データ更新の記録。

## 2026-08-14〜15: ページ新設・初期データ

- `song-views.html`（JP/EN/ID）を新設。全75曲のソロ楽曲について、実装日時点の再生数（Wayback Machineから実測）と現在の再生数を比較する一覧表を作成。
- 見出しクリックでの並び替え機能を実装。

## 2026-08-15〜19: 楽曲別推移グラフページ

- 曲ごとに `holo_pokajan/songs/{videoId}.html` を作成し、リリース日〜現在のYouTube再生数推移をSVGグラフで表示する機能を追加。
  - グラフ原点はリリース日・再生数0で固定。ホロドリ実装日を赤い縦線で表示。
  - 点は表示せず、ホバー時のみツールチップで詳細表示。
- 試作としてビビデバ（星街すいせい）1曲でデザインを固め、残り74曲に展開。
- archive.org（Wayback Machine）から過去の再生数を収集し、各曲のグラフを2〜7点程度の実データで構成。安定性の問題で全曲を複数回に分けて収集・追加（52曲→72曲まで拡充、ω猫など一部は史料がほぼ存在せず断念）。
- `song-views.html` に「推移グラフ」列（📈アイコン）を追加し、各曲ページへの導線を設置。

## 2026-08-19: バグ修正・データ整合性の回復

- **ソート機能のバグ修正**：推移グラフ列に `data-key` がなく、並び替え時のリセット処理で矢印要素が見つからずTypeErrorが発生していた問題を修正。
- **表と個別ページの再生数ズレを修正**：表（ROWS）だけ再生数を更新し、個別ページ側の同期を忘れていたため「更新されていない曲がある」状態になっていた。全74ページを同期する処理を実施。
- **バックアップデータの復元**：直前バックアップ（8/15時点、8/14時点、8/11時点）に残っていた過去の実測値を、各曲グラフの実データ点として追加し直した。

## 2026-08-21: 「勢い」列の追加

- 各曲の楽曲別ページからリリース日を取得し、以下の指標で「ホロドリ実装後にどれだけ勢いが増したか」を表に追加。
  ```
  勢い = (実装日〜現在の再生数 ÷ 経過日数) ÷ (リリース日〜実装日の再生数 ÷ 経過日数)
  ```
  - 1.5倍以上🔥、2倍以上🔥🔥、3倍以上🔥🔥🔥。背景色も段階的に強調。
  - リリースと実装が同日の新曲、および実装日時点データがない曲（ω猫）は対象外。
  - JPページのみ対応（EN/IDは楽曲別ページ自体がないため未対応）。
  - 計算に使う基準日 `NOW_DATE` は再生数更新のたびに手動更新が必要。

## 2026-08-22〜23: Oshi Mode ON追加・Full ver.再生数の合算

- 『Oshi Mode ON』クレイジー・オリー（2026/8/22リリース・実装、0再生スタート）を追加。
- NIGHTBREAK・万歳☆満開・Oshi Mode ONの3曲は、MV公開の翌日に「Full ver.」動画が別途公開されていることが判明。以後この3曲は **MV版＋Full ver.版の再生数を合算**して「現在の再生数」として扱うよう変更。
  - 各曲の個別ページにMV・Full ver.両方のリンクを掲載し、内訳（MV: X回 + Full ver.: Y回）を明記。
  - 表の再生数更新時は、この3曲についてMV・Full両方の動画IDを個別取得して合算する必要がある。

## 2026-08-21・23: 全曲一括の再生数更新（2回実施）

- 全曲（78→79曲）の現在の再生数を再取得し、表・個別ページ双方を同期する作業を実施。
- 更新前データは毎回 `holo_pokajan/data/song-views-backups/{日付}/` にバックアップ。
- 個別ページのPOINTS配列は上書きではなく、旧「現在」ポイントの note から「現在」の文字だけ外して残し、新しい日付・値のポイントを追記する方式（実データを消さない）。
- 「伸び率の平均・中央値」の説明文（callout）はROWS更新スクリプトが自動反映しないため手動更新が必要と判明。8/21・8/23の2回連続で更新し忘れる事故があり、その都度修正。

## 2026-08-24: 再生数更新の自動化（pokajan-tools）

- 公開サイトフォルダ外に`pokajan-tools`（YouTube Data APIキーを使うNodeスクリプト一式）を新設。`node scripts/fetch-views.js && node scripts/update-views.js`の2コマンドで、表(ROWS)・NOW_DATE・伸び率callout・個別ページのmeta-badge/stat-tile/desc-block本文/footer日付/POINTS配列まで一括更新できるようにした。
- 導入時点で個別ページ側のmeta-badge/stat-tile/desc-block/footer日付が自動更新対象から漏れていたのを発見・修正（表とページの数値がズレる問題が再発していた）。
- 表側(song-views.html/en/id)のfooter日付も同様に自動更新対象に追加。

## 既知の制約・今後の課題

- 楽曲別推移グラフページ（`holo_pokajan/songs/*.html`）と「勢い」列はJPページのみ対応。EN/ID版には未展開。
- ω猫（AZKi）はarchive.orgにほぼ史料が存在せず、実装日時点の再生数データなし（対象外表示）。
- Full ver.再生数合算の対象は現状5曲（NIGHTBREAK・万歳☆満開・Oshi Mode ON・天たこ観測・星屑カプセル）。今後同様のパターン（MV+Full二本立て公開）の曲が増えた場合は都度`song-config.json`への登録が必要。
- 新曲追加（ROWSへの行追加・個別ページ作成）は`update-views.js`の対象外で、引き続き手作業（またはClaudeへの依頼）が必要。
