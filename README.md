# ポカジャン攻略Lab

ホロライブドリームス（ホロドリ）のミニゲーム「ポカジャン」に特化した非公式ファンサイトです。

## ページ構成

- [index.html](index.html) — トップページ
- [rules.html](rules.html) — ルール・遊び方
- [yaku.html](yaku.html) — 役一覧・点数表
- [strategy.html](strategy.html) — 戦術・安全牌の読み方
- [holomen-board.html](holomen-board.html) — ホロメンボードと獲得コインの関係

## 技術構成

静的HTML / CSS / JavaScript のみ（ビルド不要）。`css/style.css` に共通スタイル、`js/script.js` に共通スクリプトをまとめています。

## コメント機能

各ページ下部に [giscus](https://giscus.app)（GitHub Discussions ベース）のコメント欄を設置しています。
